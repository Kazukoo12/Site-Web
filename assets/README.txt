Placez ici vos fichiers de ressources :

- CV PDF : nommez-le exactement `CV-Lucas-Fernandes.pdf` pour que le bouton de téléchargement fonctionne.
- Photo : nommez-la `photo.jpg` et remplacez le bloc "Photo ici" dans `index.html` si vous souhaitez l'afficher.

Exemple :
  assets/CV-Lucas-Fernandes.pdf
  assets/photo.jpg

 Si vous préférez ne pas utiliser EmailJS, vous pouvez utiliser `mailto:` (le formulaire ouvrira le client mail local avec le message pré-rempli). C'est déjà configuré si vous avez remplacé le script EmailJS par l'option `mailto:` dans `contact.html`.
